Entrega do projeto em formato ZIP.

Deve-se entregar para seu projeto os arquivos

1 - MD (obrigatoriamente seguindo o modelo fornecido)

2 - HTML + CSS (página completa) + código fonte

Entregar em um arquivo ZIP contendo todos os arquivos.

Basta um integrante do grupo enviar.

Seguir a seguinte regra para o nome do arquivo:

GRUPO-[99]-SEMANA-[99].zip

A composição da nota é

Protótipo = 0-100%

Documentação = 0-100%

Nota = (protótipo + documentação) / 2
